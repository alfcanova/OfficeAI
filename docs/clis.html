🤖 CLIs de IA Verificando...

Ferramentas de linha de comando para assistencia de codigo com inteligencia artificial.

Visao Geral

O OfficeAI oferece instalacao isolada para 9 CLIs de IA populares. Cada CLI e instalada em seu proprio diretorio dentro de lib/, com scripts de ambiente gerados automaticamente para ativar/desativar o PATH.

OpenCode Verificando...

Interface de linha de comando para o OpenCode, ferramenta de assistencia de codigo com IA. Suporta multiplos provedores de LLM.

🔗 opencode.ai
Binarioopencode
MetodoScript de instalacao / binario direto / npm
Executaveis
  • opencode

    • ✅ Ativar Clique para executar

    source $OFFICEAI_ROOT/bin/02.01_setenv_opencode.sh

    ❌ Desativar Clique para executar

    source $OFFICEAI_ROOT/bin/02.01_unsetenv_opencode.sh

    Uso

    # Iniciar assistente de codigo
opencode

# Comandos dentro do assistente
/help

    Pi Verificando...

    Agente de programacao minimalista e extensivel. Adaptado ao seu fluxo de trabalho, nao o contrario. Suporta 15+ provedores e centenas de modelos.

    🔗 pi.dev 💻 GitHub 📦 npm
    Binariopi
    MetodoScript oficial / npm / pnpm / bun
    Pacote@earendil-works/pi-coding-agent
    Executaveis
  • pi

    • ✅ Ativar Clique para executar

    source $OFFICEAI_ROOT/bin/02.10_setenv_pi.sh

    ❌ Desativar Clique para executar

    source $OFFICEAI_ROOT/bin/02.10_unsetenv_pi.sh

    Recursos

    • Modos: interativo, print/JSON, RPC, SDK
    • 15+ provedores: Anthropic, OpenAI, Google, Ollama, etc.
    • Historico em arvore com branches
    • Extensivel via extensions, skills e packages
    • AGENTS.md e SYSTEM.md para contexto

    Uso

    # Iniciar modo interativo
pi

# Modo print
pi -p "explique este codigo"

# Trocar modelo
# Ctrl+L ou /model

# Instalar extensao
pi install npm:@foo/pi-tools

    Instalacao

    Execute o menu interativo da Fase 02:

    ./scripts/02.00_CLIs.sh

    Ou instale individualmente:

    # Exemplo: instalar Aider
./scripts/02.03_CLIsAider.sh
