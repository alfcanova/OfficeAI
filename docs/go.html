Descricao

Go (Golang) e instalado como binario oficial extraido para o diretorio do projeto. O Go e amplamente utilizado para servicos backend, APIs, microservicos e ferramentas de linha de comando.


A instalacao inclui ferramentas essenciais para desenvolvimento: gopls (language server), dlv (debugger), staticcheck (analisador estatico) e golangci-lint (linter aggregator).

Informacoes de Instalacao

Versao 1.22.5
Metodo Binario oficial
Diretorio $OFFICEAI_ROOT/lib/go/
Executaveis
  • go
  • gofmt
  • gopls
  • dlv
  • staticcheck
  • golangci-lint

Ambiente

✅ Ativar Clique para executar

source $OFFICEAI_ROOT/bin/01.03_setenv_go.sh

❌ Desativar Clique para executar

source $OFFICEAI_ROOT/bin/01.03_unsetenv_go.sh

Variaveis de Ambiente

PATH Adiciona $OFFICEAI_ROOT/lib/go/bin/
GOPATH $HOME/go

Uso

# Criar modulo
go mod init github.com/usuario/projeto

# Executar
go run main.go

# Compilar
go build -o meu-app

# Baixar dependencias
go mod tidy

# Rodar testes
go test ./...

# Instalar ferramenta
go install golang.org/x/tools/gopls@latest
