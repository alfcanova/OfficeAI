OfficeAI

Sistema modular de instalacao e gerenciamento de ferramentas de desenvolvimento.

O que e o OfficeAI?

O OfficeAI e um conjunto de scripts bash para instalacao e gerenciamento de ferramentas de desenvolvimento em ambiente Linux. Cada ferramenta e instalada de forma isolada dentro do diretorio do projeto, evitando conflitos com o sistema operacional.


O sistema gera automaticamente arquivos de ambiente (env / unenv) para cada linguagem instalada, permitindo ativar e desativar facilmente o PATH e as variaveis de ambiente necessarias.

Como Funciona

1. Instalacao

./scripts/00_SystemBase.sh

Executa o script de instalacao com menu interativo. Tudo e instalado dentro da pasta OfficeAI (lib/ + bin/), nada escapa.

2. Ativar Ambiente

source $OFFICEAI_ROOT/etc/00_envGeneral.sh

Adiciona ao PATH todos os executaveis das ferramentas instaladas no OfficeAI.

3. Desativar Ambiente

source $OFFICEAI_ROOT/etc/00_unenvGeneral.sh

Remove do PATH todos os executaveis e desfaz as variaveis de ambiente.

4. Ativar/Desativar Individualmente

# Ativar apenas Rust
source $OFFICEAI_ROOT/bin/01.01_setenv_rust.sh

# Desativar apenas Rust
source $OFFICEAI_ROOT/bin/01.01_unsetenv_rust.sh
