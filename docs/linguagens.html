💻 Linguagens de Programacao Verificando...

Ambientes de desenvolvimento isolados para 5 linguagens populares.

Visao Geral

O OfficeAI instala cada linguagem de forma isolada dentro do diretorio do projeto, evitando conflitos com o sistema operacional. Scripts de ambiente sao gerados automaticamente para ativar/desativar o PATH e variaveis de ambiente.

🐍 Python + uv

Linguagem interpretada de alto nivel + gerenciador de pacotes ultra-rapido. Python e instalado via apt para compatibilidade com o sistema. uv substitui pip, pip-tools e virtualenv com velocidade excepcional.

🔗 python.org 🔗 uv - Astral
Metodoapt (sistema)
Executaveis
  • uv
  • uvx

    • ✅ Ativar Clique para executar

    source $OFFICEAI_ROOT/bin/00_setenv_SystemBase.sh

    ❌ Desativar Clique para executar

    source $OFFICEAI_ROOT/bin/00_unsetenv_SystemBase.sh

    Uso

    uv venv                        # Criar ambiente virtual
uv pip install requests        # Instalar pacotes
uvx ruff check .               # Executar ferramenta

    ⚡ Zig

    Linguagem de sistemas com compilador integrado que tambem funciona como gerenciador de pacotes e build system. Elimina a necessidade de CMake ou Make. Tambem e amplamente usada para cross-compilacao de projetos C/C++ existentes.

    🔗 ziglang.org 🔗 Zig Docs
    Versao0.13.0
    MetodoBinario oficial
    Executaveis
  • zig

    • ✅ Ativar Clique para executar

    source $OFFICEAI_ROOT/bin/01.02_setenv_zig.sh

    ❌ Desativar Clique para executar

    source $OFFICEAI_ROOT/bin/01.02_unsetenv_zig.sh

    Uso

    zig build-exe main.zig          # Compilar executavel
zig run main.zig                 # Executar direto
zig init                         # Inicializar projeto
zig build                        # Build com build.zig
zig test src/main.zig            # Testar
