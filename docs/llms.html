🧠 Servidores LLM Verificando...

Servidores para executar modelos de linguagem localmente com API compativel.

Visao Geral

O OfficeAI oferece instalacao para 6 servidores LLM populares. Cada servidor e instalado em seu proprio diretorio dentro de lib/, com scripts de ambiente gerados automaticamente. A maioria oferece API compativel com OpenAI para integracao facil.

Tabela Comparativa

Servidor Porta API OpenAI Metodo GPU
vLLM 8000 ✅ Docker / pip NVIDIA / AMD
Ollama 11434 ❌ Nativo Script oficial Auto-config
llama.cpp 8080 ✅ Binario pre-compilado NVIDIA / AMD / Vulkan
LocalAI 8080 ✅ Docker / binario NVIDIA / AMD
Jan AI 1337 ✅ AppImage / .deb Via backend
LM Studio 1234 ✅ (/v1) Script oficial Via backend

vLLM Verificando...

Motor de servico LLM de alta performance com API compativel com OpenAI. Otimizado para throughput elevado com suporte a batching continuo.

🔗 docs.vllm.ai 💻 GitHub
Porta8000
MetodoDocker (principal) / pip/uv (fallback)
Imagemvllm/vllm-openai:latest
Modelo PadraoQwen/Qwen3-0.6B
Dir. Instalacaolib/vllm/

Variaveis de Ambiente

VLLM_API_URLhttp://127.0.0.1:8000
VLLM_WORKSPACE$HOME/.vllm
HF_TOKENToken HuggingFace (opcional)

✅ Ativar Clique para executar

source $OFFICEAI_ROOT/bin/03.01_setenv_vllm.sh

❌ Desativar Clique para executar

source $OFFICEAI_ROOT/bin/03.01_unsetenv_vllm.sh

Uso

# Iniciar com Docker
vllm-start

# Parar
vllm-stop

# Ou via pip
vllm-serve

# Testar API
curl http://127.0.0.1:8000/v1/models

Ollama Verificando...

Runner local de LLM leve e simples. Gerencia modelos automaticamente com CLI intuitivo e suporte a multiplos modelos simultaneos.

🔗 ollama.com 💻 GitHub
Porta11434
MetodoScript oficial
APINativa Ollama
Modelos Paralelos2 (configuravel)
Dir. Modelos$HOME/.ollama/models

Variaveis de Ambiente

OLLAMA_HOSThttp://127.0.0.1:11434
OLLAMA_MODELS$HOME/.ollama/models
OLLAMA_KEEP_ALIVE24h
OLLAMA_NUM_PARALLEL4
OLLAMA_MAX_LOADED_MODELS2

✅ Ativar Clique para executar

source $OFFICEAI_ROOT/bin/03.02_setenv_ollama.sh

❌ Desativar Clique para executar

source $OFFICEAI_ROOT/bin/03.02_unsetenv_ollama.sh

Uso

# Listar modelos disponiveis
ollama list

# Baixar modelo
ollama pull qwen2.5-coder:14b

# Executar modelo
ollama run llama3.1:8b

# Listar modelos online
curl http://127.0.0.1:11434/api/tags

llama.cpp Verificando...

Port C/C++ do Meta LLaMA. Leve, portavel e nativo em GGUF. Inclui suite completa de ferramentas para inferencia, quantizacao e benchmarks.

💻 GitHub
Porta8080
MetodoBinario pre-compilado
APIOpenAI-compatible
FormatoGGUF (nativo)

Ferramentas Incluidas

llama-serverServidor API principal
llama-cliCLI interativo
llama-benchBenchmarking
llama-quantizeQuantizacao de modelos
llama-perplexityAvaliacao de perplexidade
llama-embeddingGeracao de embeddings
llama-gguf-splitDivisao de arquivos GGUF

Variaveis de Ambiente

LLAMA_CPP_HOME$HOME/.local/lib/llama.cpp
LLAMA_SERVER_HOST127.0.0.1
LLAMA_SERVER_PORT8080

✅ Ativar Clique para executar

source $OFFICEAI_ROOT/bin/03.03_setenv_llamacpp.sh

❌ Desativar Clique para executar

source $OFFICEAI_ROOT/bin/03.03_unsetenv_llamacpp.sh

Uso

# Iniciar servidor
llama-server -m ./model.gguf

# CLI interativo
llama-cli -m ./model.gguf

# Quantizar modelo
llama-quantize ./model-f16.gguf ./model-q4_0.gguf Q4_0

# Benchmark
llama-bench -m ./model.gguf

LocalAI Verificando...

Substituto drop-in para a API OpenAI. Suporta multiplos backends (llama.cpp, GPT4ALL, whisper, Stable Diffusion) com interface web integrada.

🔗 localai.io 💻 GitHub
Porta8080
MetodoDocker (principal) / binario / script
Imagemlocalai/localai:latest-gpu-nvidia-cuda-12
Containerlocal-ai (restart: unless-stopped)
WebUIIntegrada na porta 8080

Variaveis de Ambiente

LOCALAI_API_URLhttp://127.0.0.1:8080
LOCALAI_MODELS$HOME/.localai/models

✅ Ativar Clique para executar

source $OFFICEAI_ROOT/bin/03.04_setenv_localai.sh

❌ Desativar Clique para executar

source $OFFICEAI_ROOT/bin/03.04_unsetenv_localai.sh

Uso

# Listar modelos
curl http://127.0.0.1:8080/v1/models

# Requisicao completions
curl http://127.0.0.1:8080/v1/completions \
  -d '{"model": "model-name", "prompt": "Hello"}'

# Acessar WebUI
# Abra http://127.0.0.1:8080 no navegador

LM Studio Verificando...

Aplicacao desktop e CLI headless para descobrir, baixar e executar LLMs locais. Modo headless ideal para servidores sem interface grafica.

🔗 lmstudio.ai
Porta1234
MetodoScript oficial (headless)
APIOpenAI-compatible (/v1)
CLIlms / llmster
ArquiteturaDaemon-based

Variaveis de Ambiente

LM_STUDIO_HOME$HOME/.lmstudio
LM_STUDIO_API_URLhttp://127.0.0.1:1234/v1

✅ Ativar Clique para executar

source $OFFICEAI_ROOT/bin/03.06_setenv_lmstudio.sh

❌ Desativar Clique para executar

source $OFFICEAI_ROOT/bin/03.06_unsetenv_lmstudio.sh

Uso

# Listar modelos locais
lms ls

# Baixar modelo
lms get qwen2.5-coder-14b

# Iniciar daemon
lms daemon up

# Iniciar servidor API
lms server start

# Parar servidor
lms server stop

Instalacao

Execute o menu interativo da Fase 03:

./scripts/03.00_LlmServers.sh

Ou instale individualmente:

# Exemplo: instalar Ollama
./scripts/03.02_LlmOllama.sh

# Exemplo: instalar vLLM
./scripts/03.01_LlmvLLM.sh
