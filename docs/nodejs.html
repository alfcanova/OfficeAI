🟢 Node.js LTS Disponivel

Runtime JavaScript para desenvolvimento de aplicacoes backend e ferramentas CLI.

🔗 nodejs.org 🔗 npm docs

Descricao

Node.js e instalado via repositorio NodeSource, fornecendo a versao LTS (Long Term Support) com suporte de seguranca prolongado. Inclui npm (Node Package Manager) para gerenciamento de pacotes.


A instalacao inclui ferramentas globais uteis para desenvolvimento: pnpm, eslint, prettier, typescript, ts-node e nodemon.

Informacoes de Instalacao

Metodo NodeSource (apt)
Diretorio Sistema
Executaveis
  • node
  • npm
  • npx
  • pnpm
  • tsc
  • ts-node
  • nodemon

Ambiente

✅ Ativar Clique para executar

source $OFFICEAI_ROOT/bin/01.04_setenv_nodejs.sh

❌ Desativar Clique para executar

source $OFFICEAI_ROOT/bin/01.04_unsetenv_nodejs.sh

Variavel de Ambiente

PATH Adiciona $OFFICEAI_ROOT/lib/node/bin/

Uso

# Criar projeto
mkdir meu-projeto && cd meu-projeto
npm init -y

# Instalar dependencias
npm install express

# Executar com nodemon
nodemon src/index.js

# Compilar TypeScript
tsc --init
tsc -w
