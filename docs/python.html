🐍 Python + uv Disponivel

Linguagem interpretada de alto nivel + gerenciador de pacotes ultra-rapido.

🔗 python.org 🔗 uv - Astral

Descricao

Python e instalado via apt (sistema padrao do Debian), garantindo compatibilidade com ferramentas do sistema que dependem do Python.


uv e um gerenciador de pacotes Python desenvolvido pela Astral, escrito em Rust. E extremamente rapido para instalacao de pacotes e criacao de ambientes virtuais, substituindo pip, pip-tools e virtualenv.

Informacoes de Instalacao

Python apt (sistema)
uv $OFFICEAI_ROOT/lib/languages/uv/
Links em bin/
  • uv
  • uvx

Ambiente

✅ Ativar Clique para executar

source $OFFICEAI_ROOT/bin/00_setenv_SystemBase.sh

❌ Desativar Clique para executar

source $OFFICEAI_ROOT/bin/00_unsetenv_SystemBase.sh

Variavel de Ambiente

PATH Adiciona $OFFICEAI_ROOT/lib/languages/uv/

Uso

# Criar ambiente virtual
uv venv

# Instalar pacotes
uv pip install requests

# Instalar ferramenta
uvx ruff check .

# Buscar pacotes
uv pip search flask
