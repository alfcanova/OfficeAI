🔵 Rust + Cargo Disponivel

Linguagem de sistemas com seguranca de memoria e gerenciador de pacotes Cargo.

🔗 rust-lang.org 🔗 Cargo Book 🔗 rustup.rs

Descricao

Rust e instalado via rustup, o instalador oficial, em um diretorio isolado dentro do projeto. O CARGO_HOME e RUSTUP_HOME apontam para o diretorio de instalacao local.


Cargo e o gerenciador de pacotes e sistema de build do Rust, incluindo gerenciamento de dependencias, compilacao, testes e publicacao de pacotes.

Informacoes de Instalacao

Metodo rustup
Diretorio $OFFICEAI_ROOT/lib/rust/
Executaveis
  • rustc
  • cargo
  • rustup
  • rustfmt
  • clippy-driver
  • rust-analyzer

Ambiente

✅ Ativar Clique para executar

source $OFFICEAI_ROOT/bin/01.01_setenv_rust.sh

❌ Desativar Clique para executar

source $OFFICEAI_ROOT/bin/01.01_unsetenv_rust.sh

Variaveis de Ambiente

PATH Adiciona $OFFICEAI_ROOT/lib/rust/bin/
CARGO_HOME $OFFICEAI_ROOT/lib/rust
RUSTUP_HOME $OFFICEAI_ROOT/lib/rust

Cargo Tools Instaladas

cargo-editAdicionar/remover dependencias via CLI
cargo-watchRecompilar automaticamente ao alterar arquivos
cargo-nextestExecutor de testes paralelo e rapido
cargo-auditVerificar vulnerabilidades em dependencias
cargo-denyGerenciar licencas e dependencias proibidas

Uso

# Criar novo projeto
cargo new meu-projeto
cd meu-projeto

# Compilar e executar
cargo run

# Rodar testes
cargo test

# Verificar codigo (lint)
cargo clippy

# Formatar codigo
cargo fmt

# Instalar crate
cargo install ripgrep
