🔧 Sistema Base

Compiladores LLVM/Clang, GCC e ferramentas de build para desenvolvimento nativo.

🔗 Debian 13 (Trixie) 🔗 Pacotes Debian 🔗 LLVM/Clang

Descricao

O Sistema Base fornece os compiladores e ferramentas de build essenciais para desenvolvimento C, C++ e Rust. Todos os pacotes sao instalados individualmente via apt (Debian/Ubuntu), sem uso de meta-packages como build-essential.


Os compiladores e ferramentas sao instalados nos caminhos padrao do sistema (/usr/bin/), nao dentro do diretorio OfficeAI, pois sao compartilhados por todo o sistema.

Compiladores C/C++

GCC Disponivel

GNU Compiler Collection - compilador C/C++ padrao do Linux.

Pacote: gcc

G++ Disponivel

Compilador C++ do GNU.

Pacote: g++

Clang Disponivel

Compilador LLVM para C/C++/ObjC. Alternativa moderna ao GCC.

Pacote: clang

Clangd Disponivel

Language server para C/C++ (IDE support, completion, diagnostics).

Pacote: clangd

LLVM Disponivel

Coletanea de ferramentas e bibliotecas para compiladores.

Pacote: llvm

LLD Disponivel

Linkador LLVM - mais rapido que ld do GNU.

Pacote: lld

LLDB Disponivel

Debugger LLVM - alternativa ao GDB.

Pacote: lldb

Build Tools

Make Disponivel

Build tool classico baseado em Makefiles.

Pacote: make

CMake Disponivel

Gerador de sistemas de build multiplataforma.

Pacote: cmake

Ninja Disponivel

Sistema de build pequeno e rapido. Usado pelo CMake e Rust.

Pacote: ninja-build

Meson Disponivel

Sistema de build moderno e simples. Usado pelo GNOME, systemd.

Pacote: meson

pkg-config Disponivel

Descobre flags de compilacao e linking de bibliotecas.

Pacote: pkg-config

Instalacao

# Pelo menu interativo
./scripts/00_InstallSystemBase.sh
# Selecionar opcao 1 (Compiladores) e/ou 2 (Build Tools)

# Ou instalar individualmente via apt
sudo apt-get install -y gcc g++ clang clangd llvm lld lldb
sudo apt-get install -y make cmake ninja-build meson pkg-config

Ambiente

Estes pacotes sao instalados nos caminhos padrao do sistema (/usr/bin/), portanto nao precisam de arquivos env/unenv. Ja estao disponiveis no PATH do sistema.

Caminho /usr/bin/ (padrao do sistema)
env/unenv Nao necessario
Para verificar se uma ferramenta esta instalada: comando --version — Ex: gcc --version, clang --version
