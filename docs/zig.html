Descricao

Zig e uma linguagem de sistemas projetada para ser mais robusta e previsivel que C/C++. Seu compilador e tambem um gerenciador de pacotes e build system, eliminando a necessidade de ferramentas externas como CMake ou Make.


Zig e amplamente utilizado para compilar projetos C/C++ existentes e como ferramenta de build para outros projetos que precisam de compilacao nativa.

Informacoes de Instalacao

Versao 0.13.0
Metodo Binario oficial
Diretorio $OFFICEAI_ROOT/lib/zig/
Executaveis
  • zig

Ambiente

✅ Ativar Clique para executar

source $OFFICEAI_ROOT/bin/01.02_setenv_zig.sh

❌ Desativar Clique para executar

source $OFFICEAI_ROOT/bin/01.02_unsetenv_zig.sh

Variavel de Ambiente

PATH Adiciona $OFFICEAI_ROOT/lib/zig/

Uso

# Compilar projeto
zig build-exe main.zig

# Executar
zig run main.zig

# Compilar para C (cross-compile)
zig build-lib mylib.zig -target aarch64-linux-gnu

# Inicializar build system
zig init

# Rodar build
zig build

# Testar
zig test src/main.zig
